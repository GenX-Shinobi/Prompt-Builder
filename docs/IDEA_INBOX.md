# Idea Inbox

A safe place to capture ideas without turning every idea into an immediate development task. Nothing here is a commitment until it is promoted into the roadmap by agreement with the project owner.

## Capture rule

Add ideas in plain language. Do not require the owner to prioritise, categorise or fully specify an idea at the moment it is shared. Preserve the original intent; add clarifying notes separately.

## Triage labels

- **Core:** directly improves prompt building, chatbot choice, clarity, reliability or transfer.
- **Useful:** a practical improvement that supports the core experience.
- **Explore:** interesting possibility needing research, prototype or user feedback.
- **Parked:** valid idea intentionally deferred to protect focus.
- **Promoted:** moved into an agreed roadmap milestone.

## Captured ideas

### Core

- **Guided Path:** help a first-time user describe their goal in ordinary language and build a prompt without needing to understand prompt engineering.
- **Chatbot/task recommendation:** suggest an appropriate chatbot for a task, explaining free access, account requirements, limits and paid-only capabilities honestly.
- **Freshness-aware chatbot catalogue:** per-entry verification date, status, source and notes; clearly distinguish confirmed, conflicting and unverified information.
- **Reliable prompt transfer:** consistent multi-part instructions, clear part numbering, acknowledgement and completion protocol.
- **First-use clarity:** a new user should be able to open the app and create/use a useful prompt without assistance.

### Useful

- **Preset portability:** validated import/export, merge-by-name behaviour and sensible limits.
- **Attachment clarity:** distinguish content embedded into the prompt from files that the user must upload manually; warn when inline content consumes the paste budget.
- **Safer splitting:** avoid splitting Unicode surrogate pairs and keep protocol instructions consistent.
- **Better estimates:** make character/token counts and chatbot paste budgets clearly labelled as estimates, not provider guarantees.
- **Session checkpoint:** compact handoff for a long task or multi-part exchange.
- **Task loadouts:** reusable combinations of prompt settings for common tasks.
- **Settings portability:** optional export/import for palette and layout preferences.

### Explore

- **Real-world problem solving beyond work and coding:** support practical questions, learning, hobbies and gameplay roadblocks. The owner's use of the builder to solve problems while playing Grounded 2 on PlayStation 5 is an example of the broad audience and task range.
- **Teacher/tester feedback:** invite a teacher or other first-time user to try the app; record observed friction rather than assuming demand.
- **Free-tier tool comparison:** evaluate how the same task performs across available free chatbot tiers without allowing premium subscriptions to redefine the baseline.

### Parked

- Full folder/repository-scale context packer.
- Cloud synchronisation, user accounts or hosted prompt storage.
- Large feature expansions before v5.4 recovery and first-use testing.
