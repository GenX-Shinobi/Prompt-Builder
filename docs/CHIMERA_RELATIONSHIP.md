# CHIMERA — Relationship to AI Prompt Builder Hub

**Status:** Informational boundary note; not an integration authorization.

CHIMERA is a separate public repository: https://github.com/GenX-Shinobi/CHIMERA

It is intended to become an open-source, free-to-use, platform-independent framework for reusable AI workforces. Prompt Builder v5.4.0 has been formally released, so the release precondition is met; AI Prompt Builder Hub may become CHIMERA's first adopter only if the owner separately approves a bounded integration milestone.

The projects retain separate repositories, roadmaps, statutes, memory, task queues, release processes and approval authority. No CHIMERA employee or memory permission automatically transfers to Prompt Builder, and Prompt Builder's project-specific rules do not automatically transfer to CHIMERA.

Any future integration must be assessed against Prompt Builder's own free-first mission, standalone zero-dependency architecture, user needs and scope. This note does not change current release gates, authorize changes to application code, authorize a merge or release, or start v5.5.0.

**Current boundary:** v5.4.0 is published as a GitHub Release (tag `v5.4.0`). That release does not authorize CHIMERA integration: no CHIMERA integration work is active or approved. For the current project state see [CURRENT_STATUS.md](CURRENT_STATUS.md).
