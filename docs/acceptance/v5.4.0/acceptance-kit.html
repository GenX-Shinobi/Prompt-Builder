AI Prompt Builder Hub v5.4.0 - Acceptance Kit

Built for release commit 023171dc60af78d43081a447d41009f153d82127 on branch release/v5.4.0. You only need your web browser. No terminal, no editing, no developer tools.

Before you start (5 minutes, once)

  1. Download the real release app: open index.html on the release branch and use the Download raw file button (the down-arrow icon at the top right of the file). Save it somewhere you can find it.
  2. Double-click the saved index.html to open it in your browser. It works offline.
  3. Scroll to Dev Bay, then the Chatbot catalog box. You will use Import catalog there.
  4. Keep this page open next to the app (two windows or two tabs).

Nothing is installed unless you press "Install and reload". Every test below ends with Cancel. If you ever press Install by accident, click Use built-in catalog in the same box and everything is back to normal; your saved presets are never touched.

Tip: after each test press Cancel, then start the next. You can stop at any time; tests you skip count as "Not tried".

Test 1: Add one command and remove another

  1. Press Copy test 1 here:
  2. In the app, click Import catalog, click inside the box, paste (Ctrl+V, or Cmd+V on a Mac), then click Validate & preview changes.
  3. You should see:

    • A line starting "- Claude: Extended thinking / effort (Chat menu (+ button, or type /))".
    • A line about the catalogue revision ("rev 1 -> 2").
    • The summary says 3 in total.
  4. Then try:
    • Click the "+ ChatGPT" line. It opens and shows ten labelled values, including: group Acceptance Group, kind ask, free-tier badge account, text added to the prompt "ACCEPTANCE prompt text for ACCEPTANCE TEST added command", description, where to find it, fill-in boxes, check date 2026-11-20, status confirmed.
    • Click the "- Claude" line. It opens and shows the old values of that command (its text, description, badge and so on), not blanks.
  5. Keyboard check: without the mouse, press Tab until a line is outlined, press Enter to open it and Enter again to close it; do the same with Space. Shift+Tab goes back.
  6. Finish by clicking Cancel. Never press "Install and reload".
